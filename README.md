# Portfolio électronique SBI4U — Alex Hum

Portfolio du cours de Biologie 12e (SBI4U, M. Mark, É.s.c. Sainte-Trinité, Oakville).

Site statique en une seule page (`index.html`) : aucune étape de build.
Bibliothèques chargées depuis un CDN : d3 v7.8.5 (cartes conceptuelles) et les polices Geist / Geist Mono (Google Fonts).

## Voir le site en local
Ouvrir `index.html` dans un navigateur, ou lancer un petit serveur :

```
python3 -m http.server 8000
```

puis aller à http://localhost:8000.

## Pages
Accueil · Lettre d’ouverture · Unité 1 (Biochimie cellulaire) · Unité 2 (Processus métaboliques) · Bibliographie.
La navigation se fait par ancres (`#accueil`, `#unite-1`, etc.).
